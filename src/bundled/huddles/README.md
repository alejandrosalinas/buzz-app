# Huddles

Talk with people in your channels and direct messages using live audio on desktop.

## Getting started

1. Open a channel or direct message and select the headphone button to start or join a Huddle.
2. Allow microphone access when prompted. Use the Huddle controls to mute yourself or choose an audio device.
3. Leave using the call controls when you're finished. Closing the Huddle window keeps the call connected; reopen it from the mini player beside search.

In a one-to-one DM with your voice-capable agent running on this computer, the
headphone button says **Talk with [agent]**, and starting a Huddle adds the agent
to its room. Joining an existing Huddle never adds anyone. Otherwise, add agents
with **Add someone**; parent conversation membership alone does not seat them.

On this computer, a seated agent rests at a smaller size, adds a rotating ring
(activity dots in the mini player) while it works, and returns to normal size
while it speaks. Reduced motion keeps the ring static. This state is local and
not shared with other participants.
