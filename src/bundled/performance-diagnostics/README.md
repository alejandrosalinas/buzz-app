# Performance diagnostics

Give agents a short performance snapshot of Buzz. It reports aggregate timing and activity across the communities this app retains.

## Getting started

1. Ask an agent to request **Performance diagnostics**, then approve the request in Buzz. It starts off and is unlisted in the Plugins catalog.
2. Ask an agent to run `performance_snapshot`. It samples for five seconds by default. The agent can choose a duration from one to ten seconds.

An external agent needs full-agent approval. Ask an agent to disable **Performance diagnostics** to remove the tool.
