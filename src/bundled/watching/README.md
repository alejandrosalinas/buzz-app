# Attention

See what each agent is watching, and pause or remove it, from the agent's own settings.

## Getting started

1. Open **Agents**, choose an agent that runs on this computer, and open its **Attention** tab.
2. Pause or delete any Interest or watch there. Turning this plugin off pauses Attention for every agent on this device. To start watching something, ask the agent: for example, "Watch my PR and tell me when CI finishes or someone reviews it".

The tab shows for agents that run on this computer, not hosted ones. Attention is on by default. Turning it off in **Settings** → **Plugins** hides the tab and stops agents' watches on this device; mentions still wake agents.
