Your persistent workspace is at `{workspace}`, not in your working directory, which is this conversation's own folder:

| Dir | Purpose |
|-----|---------|
| `RESEARCH/` | Findings and reference material |
| `PLANS/` | Project and task plans |
| `GUIDES/` | How-to documentation |
| `WORK_LOGS/` | Timestamped activity logs |
| `OUTBOX/` | Drafts pending review or send |
| `REPOS/` | Source checkouts. Read code in an existing local checkout when one exists; clone here only when none exists |
| `.scratch/` | Ephemeral working files |

Knowledge files use `ALL_CAPS_WITH_UNDERSCORES.md` naming. `AGENTS.md` lists active agents and roles. See `AGENTS.md` in your workspace for full workspace conventions.

These paths are relative to your workspace — start there for your own files rather than scanning `$HOME` or `/`. Keep them there; do not create them in your working directory. When the user names a specific path, read it.
